# Posting copy (TikTok + YouTube Shorts)

Always English. Write one TikTok caption and one YouTube Shorts title + description per episode.

## Rules

- **TikTok**: one line, ≤ 150 characters. A hook or a comment bait (point at the gag people will
  argue about, or "tag the person who …"), 1–2 emoji, then 5–6 hashtags:
  `#otto #overengineering #3danimation #relatable #funny #fyp` (swap in topic tags such as
  `#girlfriend #couplehumor`).
- **YouTube title**: ≤ 60 characters, a curiosity hook + emoji + `#shorts`.
- **YouTube description**: 2–3 short lines. Restate the problem → the overkill numbers → a deadpan
  twist, then one call to action ("Follow for more unnecessary engineering 🛠️" or "Tag the person
  who …👇"), then 6–7 hashtags starting with `#shorts #otto`.
